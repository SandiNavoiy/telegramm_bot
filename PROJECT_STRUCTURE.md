# 📐 Архитектура, Структура и Логика Работы Проекта

Данный документ содержит полное описание архитектуры, структуры файлов и алгоритмов работы Telegram-бота для отслеживания курсов фиатных валют (к рублю) и криптовалют (к доллару США).

---

## 📁 Структура Файлов Проекта

```text
d:\python\telegramm_bot\
├── main.py                     # Главная точка входа, обработчики команд и сообщений Telegram
├── config.py                   # Модуль конфигурации (загрузка переменных из .env)
├── database.py                 # Менеджер базы данных SQLite (подписчики, утренние курсы, алерты)
├── rates_service.py            # Сервис получения курсов (USD, EUR, BYN, CAD, GBP к RUB; BTC, ETH, SOL, KAS, XMR к USD)
├── scheduler.py                # Фоновый планировщик задач (рассылка в 09:00 МСК и часовые алерты >10%)
├── requirements.txt            # Зависимости Python
├── .env.example                # Шаблон конфигурационного файла для токенов и настроек
├── .env                        # Рабочий файл с токеном и параметрами (в .gitignore)
├── .gitignore                  # Исключения Git (база данных bot_data.db, .env, логи)
├── telegram_bot.service        # Файл службы systemd для автозапуска и работы 24/7 на Linux VPS
├── Dockerfile                  # Контейнеризация проекта для запуска через Docker
├── README.md                   # Краткая инструкция по установке и запуску
└── PROJECT_STRUCTURE.md        # Настоящий документ с подробным описанием логики
```

## 💵 Поддерживаемые Активы

1. **Фиатные валюты (к рублю RUB)**:
   - `USD` (Доллар США) — *например: 84.07 RUB*
   - `EUR` (Евро) — *например: 96.59 RUB*
   - `BYN` (Белорусский рубль) — *например: 27.88 RUB*
   - `CAD` (Канадский доллар) — *например: 59.96 RUB*
   - `GBP` (Фунт стерлингов) — *например: 112.43 RUB*

2. **Криптовалюты (к доллару США USD)**:
   - `BTC` (Bitcoin / Биткоин) — *например: $86,535.00 USD*
   - `ETH` (Ethereum / Эфириум) — *например: $2,758.22 USD*
   - `SOL` (Solana / Солана) — *например: $119.10 USD*
   - `KAS` (Kaspa / Каспа) — *например: $0.0423 USD*
   - `XMR` (Monero / Монеро) — *например: $570.97 USD*

## ⚙️ Описание Компонентов и Модулей

### 1. `config.py` — Конфигурация
- **Назначение**: Безопасная загрузка настроек из файла `.env` и переменных окружения.
- **Основные параметры**:
  - `BOT_TOKEN`: Токен Telegram-бота из `@BotFather`.
  - `API_KEY`: (Необязательно) API-ключ для APILayer.
  - `ADMIN_CHAT_ID`: (Необязательно) Telegram ID администратора.
  - `DB_PATH`: Путь к базе данных (по умолчанию `bot_data.db`).
  - `TIMEZONE`: Часовой пояс (по умолчанию `Europe/Moscow`).
  - `DEVIATION_THRESHOLD_PERCENT`: Порог срабатывания алертов (по умолчанию `10.0`%).

---

### 2. `database.py` — База Данных (SQLite)
- **Назначение**: Сохранение подписчиков и утренних базовых курсов (фиат в RUB, крипта в USD) между перезапусками сервера.
- **Таблицы в БД (`bot_data.db`)**:
  1. `subscribers`: Список активных подписчиков (`chat_id`, `username`, `subscribed_at`).
  2. `baseline_rates`: Утренние базовые курсы на 09:00 МСК (`date`, `currency`, `rate`, `updated_at`).
  3. `alerts_log`: История отправленных алертов (`date`, `currency`, `alerted_rate`, `baseline_rate`, `deviation_percent`).

---

### 3. `rates_service.py` — Сервис Котировок
- **Назначение**: Запрос курсов фиатных валют к RUB и криптовалют к USD с авто-переключением на резервные источники.
- **Источники**:
  - **Фиат к RUB**: API Центрального Банка РФ (`cbr-xml-daily.ru`) + APILayer fallback.
  - **Крипта к USD**: CoinGecko API (`vs_currencies=usd`) + CryptoCompare fallback.

---

### 4. `scheduler.py` — Планировщик и Алерты
- **Задачи**:
  1. **Утренний отчет (09:00 МСК)**:
     - Запрашивает курсы (фиат к RUB, крипта к USD).
     - Сохраняет утренние значения в БД `baseline_rates`.
     - Отправляет структурированный отчет всем подписчикам.
     - Содержит `misfire_grace_time=3600`, гарантирующий доставку даже при перезапуске сервера вокруг 9:00.
  2. **Часовая проверка (>10%)**:
     - Проверяет текущее отклонение от утреннего курса. При изменении $\ge 10\%$ рассылает алерты (без повторных спам-уведомлений в тот же день).

---

### 5. `main.py` — Бот и Меню
- **Главная клавиатура (ReplyKeyboardMarkup)**:
  - Ряд 1: `💵 USD` | `💶 EUR` | `🇧🇾 BYN`
  - Ряд 2: `🇨🇦 CAD` | `💷 GBP`
  - Ряд 3: `🟧 BTC` | `🔷 ETH` | `🟣 SOL`
  - Ряд 4: `⚡ KAS` | `🔒 XMR`
  - Ряд 5: `📊 Все курсы` | `ℹ️ Статус`
- **Дополнительные команды**:
  - `/test_report` — мгновенная тестовая отправка 09:00 МСК отчета в Telegram.
